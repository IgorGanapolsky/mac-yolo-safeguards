Claude Code, Cursor and Codex leave MCP servers and helper processes running after the session ends, fill memory and swap, and eat the disk with logs. Run a few for a day and your Mac crawls. What it does

  • Shows which agent is the problem. CPU, GPU, memory, swap and disk, with the top hogs named, so you can tell a runaway agent from Spotlight indexing.
  • Stops leftover agent processes. MCP servers and helpers that outlive their session get stopped. Apps you're using, your terminal sessions (tmux, herdr) and Cursor's own background workers are never touched.
  • Frees disk space. One click clears agent logs, old simulator runtimes and stale developer caches.
  • Works with your agents. Includes an MCP server, so Claude Code or Cursor can check your Mac's health before starting heavy work.

Why it exists

On May 26, 2026, a coding agent booted an iPhone simulator that kept forking until my Mac's load average hit 307 and it stopped responding. The guard that grew out of that night is what this app runs. Read the full incident write-up.

Every change to the stop-or-spare logic is tested against 36 recorded process snapshots, including real snapshots from a Mac running many agents. A change that would stop a process it shouldn't fails the test and doesn't ship.
