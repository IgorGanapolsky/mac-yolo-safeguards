Keep AI coding agents from freezing your Mac.

If you run Claude Code, Cursor or Codex for hours, you've probably watched your Mac slow to a crawl: memory fills up, swap grows, the disk runs out, and leftover agent processes keep running after the session ends. Mac YOLO Safeguards is a small, free menu bar app that shows you what's happening and cleans it up.

Download for Mac (free) Pricing

Version 1.2.1. macOS 14 or later on Apple Silicon. Signed with an Apple Developer ID and notarized by Apple, so it opens without warnings. Also available as a .pkg installer or with Homebrew:

brew install --cask igorganapolsky/tap/mac-yolo-safeguards

Using the full name adds the tap and, on newer Homebrew, trusts just this app, so no separate trust step is needed.

What it does

  • Shows the real load. CPU, memory, swap and disk in the menu bar, plus which app is using the most, so you can tell an agent problem from Spotlight indexing.
  • Cleans up leftover agent processes. MCP servers and helper processes that outlive their agent session get stopped. Your terminal sessions (tmux, herdr) and the apps you're using are never touched.
  • Frees disk space. One click clears agent logs in /private/tmp, old simulator runtimes and stale developer caches.
  • Works with your agents. Includes an MCP server, so Claude Code or Cursor can check your Mac's health before starting heavy work.
