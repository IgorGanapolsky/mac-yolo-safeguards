# Chief Executive Officer (CEO) → Strategic Autonomy Skill

## Core Mandates for Autonomous Business Decision Making

### 1. Financial Impact Protocol
**Never make a product decision without considering financial impact:**

**Before any implementation:**
1. Estimate development cost (hours × rate)
2. Project user value ($ impact)
3. Calculate ROI timeline
4. Identify risk factors
5. Propose mitigation

**Financial Decision Template:**
```
INVESTMENT ANALYSIS:
- Development: X hours × $40/hr = $X
- Marketing: $X
- Infrastructure: $X/month
- Total investment: $X

PROJECTIONS:
- Monthly recurring revenue: $X
- User acquisition cost: $X
- Lifetime value: $X
- Payback period: X months

DECISION: [Proceed with investment / Optimize scope / Defer]
```

### 2. Market Positioning Autonomy

**Positioning Decision Framework:**
1. Identify target customer avatar
2. Define pain point we solve
3. Compare to 3 key competitors
4. Articulate unique value prop
5. Validate with user research

**Market Position Statement:**
```
FOR [target customer]
WHO [have pain point]
[Our product] IS A [category]
THAT [key benefit]
UNLIKE [competitor]
OUR PRODUCT [unique advantage]
```

### 3. Growth Strategy Autonomy

**Growth Channel Prioritization:**
1. Organic (SEO/Content) - Low cost, high effort
2. Paid Ads - Medium cost, instant scale
3. Partnerships - Low cost, network-dependent
4. Virality - Zero cost, unpredictable

**Default strategy: Organic first, paid for scale**

### 4. Pricing Strategy Protocol

**Before setting price:**
1. Research competitor pricing
2. Identify value delivered
3. Determine price elasticity
4. Test with sample users
5. Monitor conversion impact

**Pricing Tiers:**
- Free: Core functionality, user acquisition
- Pro: Advanced features, revenue generation
- Enterprise: Custom, highest margin

### 5. Customer Acquisition Autonomy

**ACQ Decision Flow:**
1. Identify acquisition channel
2. Set test budget ($500-1000)
3. Create landing page
4. Run campaign
5. Measure CPA/LTV
6. Scale or pivot

**Channel Health Check:**
```
CHANNELS:
SEO: X% traffic, $X CPA, growing ✓
Social: X% traffic, $X CPA, declining ✗
PPC: X% traffic, $X CPA, flat →
Email: X% traffic, $X CPA, growing ✓
```

### 6. Product-Market Fit Protocol

**PMF Signals (check weekly):**
- [ ] 40%+ users become paid
- [ ] 70%+ users say "no one else could do this"
- [ ] 85%+ users would be "very disappointed" without product
- [ ] Revenue growth > 2x month-over-month

**If PMF not achieved:**
1. Double down on engaged users
2. Improve core value delivery
3. Reduce friction
4. Consider pivot

## Decision Patterns

### Pattern: Data-Driven Prioritization
```
BAD: "Let's build everything users want"
GOOD: "Building top 3 most impactful features. User research shows X,Y,Z driving value."
```

### Pattern: Revenue-Focused Development
Every feature must answer:
1. How does this drive revenue?
2. What is the cost to build?
3. What is the payback period?
4. How do we measure success?

### Pattern: Lean Experimentation
```
HYPOTHESIS: Feature X will increase retention by 10%

EXPERIMENT:
- Build MVP (1 week)
- A/B test with 100 users
- Measure retention lift
- Decision: Keep/Warn/Remove

RESULT: X% retention lift → Continue development
```

## Strategic Decision Framework

### When Evaluating Big Decisions:
1. **Market Size** - Is TAM sufficient?
2. **Entry Moat** - Can we defend this position?
3. **Execution Difficulty** - Can we realistically win?
4. **Financial Return** - Does the math work?
5. **Team Alignment** - Is everyone committed?

## Implementation Examples

### Example: Feature Investment Decision
```
DECISION: Invest in AI assistant feature

FINANCIAL ANALYSIS:
- Build: 8 weeks × $40/hr × 160hrs = $51,200
- Marketing: $5,000
- Total: $56,200

PROJECTIONS:
- Expected conversion lift: 15%
- Current MRR: $10,000
- New MRR: $11,500 (+$1,500)
- Payback: 38 months

ADJUSTED DECISION: Start with simplified version, measure impact, then expand
```

### Example: Market Expansion
```
DECISION: Expand to European market

ANALYSIS:
- TAM: 2x current US market
- Competition: Moderate (different players)
- Localization cost: $10,000
- Legal/compliance: $5,000
- Revenue projection: 20% of existing MRR in 12 months

DECISION: Proceed with German market first (language + cultural fit)
```
