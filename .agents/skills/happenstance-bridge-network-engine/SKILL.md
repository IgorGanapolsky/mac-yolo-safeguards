# Happenstance + Bridge (`brdg.app`) Network Revenue Engine

Operationalizes **Happenstance (`https://happenstance.ai`)** and **Bridge (`https://brdg.app`)** as a unified, zero-cost warm-intro and 1st-degree buyer acquisition engine for Mac YOLO Safeguards (`https://macyolosafeguards.io`) and ThumbGate (`https://thumbgate.app`).

## Why Both Together Work Better Than Either Alone

1. **Happenstance (`https://happenstance.ai`)** indexes Google Calendar, Gmail, LinkedIn, and Friend graphs to rank high-fit coding-agent and AI-security buyers (`AI coding tool buyers`, `Mac coding agent buyers`, `AI agent firewall prospects`, `ThumbGate buyer prospects`), but omits raw email addresses in chat tables.
2. **Bridge (`https://brdg.app`)** syncs 10,000+ Google OAuth contacts (`contacts__main_compressed_v2`), active 1st-degree Bridge members (`bridge_members_details__main_compressed_v2`), and shared investor/founder networks (`tags/shared__main_compressed_v2`) with full verified email addresses.
3. `tools/happenstance-bridge-network-engine.js` cross-joins Happenstance's ranked buyer intelligence with Bridge's synced contact store, routes each buyer deterministically (`team_sprint` `$499` vs `pro` `$149/yr`), enforces the Corporate Air-Gap Diode (`CORP_AIRGAP_RE`), and feeds the private revenue pipeline (`~/.hermes/business_os/revenue/`).

## Commands

```bash
# Summarize live Happenstance + Bridge pipeline coverage
node tools/happenstance-bridge-network-engine.js

# Run unit tests
node tests/test-happenstance-bridge-network-engine.js
```
