# Output quality loop

Chief owns the product lock. Treat output as an engineering problem.

## Contract first
Audience, goal, must include, must not, format, definition of done.

ThumbGate must not: Continuity as the public noun, pair a Mac, lid-close sell, Team $49, invented traction.
Must include on public copy: hosted Hermes, $10, fenced VPS.

## Stages
Context → plan → produce → deterministic validate → rubric review → repair failed criteria only (max 2).

## Ship
Only if validate + rubric pass. Otherwise return failed criteria. Do not restore Continuity or Mac-pair to please a test.
