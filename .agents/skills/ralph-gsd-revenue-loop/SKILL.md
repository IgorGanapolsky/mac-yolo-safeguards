# Ralph-Loop & GSD Revenue Engine Skill

Implements the 24/7 continuous autonomous execution loop for revenue acceleration:
1. **SENSE**: Monitors open pipeline dollars, extension packaging status, staged posts, and PR CI.
2. **PRIORITIZE**: Ranks actions by expected cash value ($3,000 Partner Pilot > $19 Pro > CI Ship).
3. **ACT (GSD)**: Dispatches outreach packets, compiles extension bundles, formats authority posts, and runs test suites.
4. **VERIFY**: Captures verifiable receipts in `coordination/ralph_loop_state.json` without asking for manual permission.

## Global System Commands

- **`bin/ralph-gsd-loop --doctor`**: Health checks Ralph-GSD engine status.
- **`bin/ralph-gsd-loop --tick`**: Runs a single autonomous GSD revenue cycle.

## Verification

```bash
# Doctor Status Check
bin/ralph-gsd-loop --doctor
```
