## Steal

1. **Description chain** — execute/handoff needs one-sentence done + 1–5 ACs
   with a named proof surface *before* the VPS acts. Ordinary chat skips this.
2. **Discernment** — five lenses (correctness, quality, fit, experience,
   responsibility). `status=completed` / receipt `outcome=done` is not quality.
3. **Cowork handoff** — whole-task needs workspace + context + deliverable.
4. **Diligence** — one call: ship / fix / stop.
