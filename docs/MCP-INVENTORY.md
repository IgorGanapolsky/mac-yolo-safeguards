## How we know it works

- Structural: `node tools/mcp-health-check.js` (CI / maturity scorecard).
- Optional live: `node tools/mcp-health-check.js --ping` (needs tokens for private servers).
- Product memory: ThumbGate MCP `recall` after `capture` (AGENTS.md protected component).

## Security rules

- Never commit MCP PATs or API keys.
- Prefer least-privilege tokens (GitHub: contents/issues/PRs only as needed).
- Local stdio servers (grepai) must not run on untrusted multi-tenant hosts.
