## 1. Tool Submission: Herdr (`herdr`)

- **Name**: Herdr
- **Tagline**: Terminal multiplexer and state manager for AI coding agents.
- **Short Description**: Herdr is an ultra-fast terminal multiplexer and agent state manager built specifically for autonomous AI coding agents (Claude, Codex, Gemini, Antigravity, Cursor, Poolside AI). It automatically tracks agent pane states (`working`, `blocked`, `done`, `idle`), restores workspace trees, and prevents nested prompt deadlocks.
- **Categories**: `AI`, `TUI`, `MACOS`, `LINUX`, `SYSADMIN`
- **Languages**: Rust, C
- **License**: Open Source / MIT
- **Author**: Igor Ganapolsky & Herdr Contributors
- **Website**: https://herdr.dev/
- **Repository**: https://github.com/herdrdev/herdr
- **Install Commands**:
  - **macOS / Linux**: `curl -fsSL https://herdr.dev/install.sh | sh`
  - **Homebrew**: `brew install herdrdev/tap/herdr`
  - **Cargo**: `cargo install herdr`
- **Image Preview**: `https://herdr.dev/assets/demo-hero.png`

## 2. Tool Submission: ThumbGate (`thumbgate`)

- **Name**: ThumbGate
- **Tagline**: Pre-action safety gates & self-improving memory for AI coding agents.
- **Short Description**: ThumbGate provides local PreToolUse safety gates and memory rules for AI coding agents (Claude, Cursor, Codex, Gemini, OpenCode, Amp). It intercepts dangerous terminal operations, secret key leaks, and un-gated paid API expenditure before tool execution, converting agent failures into enforced prevention rules across sessions.
- **Categories**: `AI`, `SECURITY`, `TUI`, `MACOS`, `LINUX`, `MONITORING`
- **Languages**: JavaScript / Node.js, Python
- **License**: MIT
- **Author**: Igor Ganapolsky
- **Website**: https://thumbgate.app/
- **Repository**: https://github.com/IgorGanapolsky/ThumbGate
- **Install Commands**:
  - **npm**: `npm install -g thumbgate`
  - **npx quickstart**: `npx thumbgate doctor`
- **Image Preview**: `https://thumbgate.app/assets/thumbgate-cli-demo.png`
