## LinkedIn (primary — operator story)

Claude Code's own Remote Control is great — until your laptop isn't on.

I've been running long agent sessions with Claude Code, and the pattern repeats: the moment I
step away, I either leave everything running unsupervised or I close the laptop and the session
just stops. Remote Control relays what's already happening on a machine that's on, awake, and
connected — nothing more.

That gap is why I've been building ThumbGate.app: chat with your agents from any browser, and
approve or deny each tool call before it runs on your Mac — even from your phone. Free to sign in
and use for web control. There's an early paid Continuity option for when the Mac itself goes to
sleep — still proving that one out in real use, so I'm not going to oversell it.

Zero customers so far. Just building this in public because "who approves the risky command at
2am" is a real problem, and I got tired of choosing between babysitting a laptop and hoping
nothing goes wrong overnight.

If you're running Claude Code (or any coding agent) unattended and have hit this — I'd like to
hear how you're handling it.
