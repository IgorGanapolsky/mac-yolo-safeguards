## LinkedIn

Claude Code asked to run `rm -rf` on a build directory while I was in a meeting. I approved it without really looking, because the alternative was staring at my terminal until it finished.

That's the actual failure mode of running autonomous coding agents: not that they're smart, but that the approval decision arrives the moment you step away, and "let it run unsupervised" quietly becomes the default.

I built ThumbGate.app so that decision follows me instead of waiting for me. It's a free browser control plane — chat with your Hermes/Claude Code/Cursor/Codex agents from any device, and approve or deny each risky tool call before it runs on your machine, from your phone if that's where you are. Leash approvals are free, on web and mobile, forever.

I'm building this myself, mostly alone, with close to no users yet — which is exactly why I want the approval gate to be the calm, boring layer between "agent wants to do something" and "agent did something," not a growth story.
