Title: Show HN: Mac YOLO Safeguards – stop AI coding agents from freezing your Mac
URL: https://macyolosafeguards.io/

I run Claude Code, Codex and Cursor agents for hours at a time on one MacBook. Every few days the machine would grind to a halt: swap kept climbing, agent logs filled the disk under /private/tmp, and MCP server processes kept running long after the session that started them had ended.

Mac YOLO Safeguards is the small menu bar app I built for that. It shows CPU, memory, swap and disk along with the process behind each one. It stops MCP servers and helper processes whose agent is gone, and it never touches tmux, herdr or the app you're working in. One click clears agent logs, old simulator runtimes and developer caches, and it leaves running sessions and databases alone. It also ships an MCP server, so an agent can check the Mac's health before it starts a heavy job.

It's free and MIT licensed, signed and notarized by Apple, and needs macOS 14 or later on Apple Silicon. The source is at https://github.com/IgorGanapolsky/mac-yolo-safeguards and the download is at https://macyolosafeguards.io/go/dmg.

One thing I learned while building it: the load average is a poor CPU signal on Apple Silicon. After a reboot, Spotlight pushed it past the core count and my own app showed 100% CPU while the processor was mostly idle. It now reads the kernel's CPU counters instead.

I'd like to hear what else makes your Mac fall over when agents run for a long time.
