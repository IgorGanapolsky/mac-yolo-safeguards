Fixes #5734.

## Problem

Team name/instructions are shared and executed at agent launch exactly like a persona's `system_prompt`, but were never routed through the invisible-character/bidirectional-override/length validation that #4220 added for personas and managed agents.

Traced the gap to three exact boundaries:

- **Local create/update** (`commands/teams.rs`): `create_team`/`update_team` only trimmed input; never validated it.
- **Inbound relay sync** (`commands/personas/inbound.rs`): the dispatcher explicitly validates `KIND_PERSONA` and `KIND_MANAGED_AGENT` content before retention ("keeps an unsafe event out of both the retention database and the local store" per its own comment), but `KIND_TEAM` was completely absent from that gate — a malicious or corrupted kind:30176 event could carry hidden Unicode-control text straight into the local store from any relay.
- **Team snapshot import** (`managed_agents/team_snapshot.rs`): per-member `system_prompt`s are validated via `validate_snapshot`, but the team-level name/instructions header was not.

## Fix

Added `validate_team_definition_text` (`definition_validation.rs`) — a thin wrapper delegating to the existing `validate_agent_definition_text` rather than reimplementing the same invisible-character/bidi-override/length rules a second time — and wired it into all three boundaries:

1. `commands/teams.rs::create_team`/`::update_team`, right after trimming, before the store lock is taken.
2. `commands/personas/inbound.rs`: added `validate_inbound_team_definition`, mirroring the existing `validate_inbound_persona_definition`/`validate_inbound_managed_agent_definition` pattern, wired into the previously-unguarded `KIND_TEAM` branch of the dispatch gate.
3. `managed_agents/team_snapshot.rs::validate_team_snapshot`, alongside the existing empty-name check.

## Tests

12 new unit tests across the three touched files, following the exact naming/assertion style already used for the equivalent persona/managed-agent tests in the same files:

- `definition_validation.rs`: `team_definition_accepts_plain_name_and_instructions`, `team_definition_accepts_absent_instructions`, `team_definition_rejects_invisible_characters_in_instructions`, `team_definition_rejects_bidirectional_override_in_name`
- `commands/personas/inbound/inbound_tests.rs`: `inbound_team_rejects_invisible_instructions`, `inbound_team_rejects_bidirectional_override_in_name`, `inbound_team_accepts_visible_multiline_instructions`, `inbound_team_accepts_absent_and_cleared_instructions`
- `managed_agents/team_snapshot.rs`: `validate_rejects_invisible_characters_in_team_instructions`, `validate_rejects_bidirectional_override_in_team_name`
